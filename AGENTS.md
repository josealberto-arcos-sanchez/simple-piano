# Instrucciones para agentes

- Lee siempre `README.md` antes de trabajar en este proyecto. Es el índice de toda la documentación.
- La documentación detallada está en `docs/`, un tema por fichero. Consulta el índice para encontrar el documento relevante.
- Si añades, quitas o renombras un documento en `docs/`, actualiza también el índice de `README.md`.
- Si cambias algo que un documento de `docs/` describe, actualiza ese documento.
